# 关闭电脑之后 · After the Laptop Closes

A ~4-minute hand-drawn animated short, drawn entirely in code.

> 深夜，主人还在写代码。屏幕里，Claude Code 的橙色小方块陪着他。
> 保存、说晚安、合上电脑、关灯离开——房间安静下来。
> 过了一会儿，合上的笔记本缝隙里亮起了一点橙色的光……

Late at night a programmer finishes work with the little orange friend who lives in his terminal,
closes the laptop and goes to bed. A while later, two eyes appear in the gap of the closed lid.
Keyboard hopscotch, a laptop that almost wakes up, a runaway pen, a sticky note with a surprise on it —
and the last cookie on the plate.

## Watch

- **Online:** https://yiggeror.github.io/small-claude/ — plays in the browser, no install.
- **`site/`** — the self-contained static website. It renders the film live on a `<canvas>`, locked to the
  soundtrack's clock (chapters, scrubbing, fullscreen, keyboard shortcuts). Serve the folder with any static
  server, e.g. `npx serve site` or `python3 -m http.server -d site`, then open it in a browser.
- **`film/after-the-laptop-closes.mp4`** — the finished film as a 1080p30 H.264/AAC video, rendered from exactly
  the same code and soundtrack.

## How it's made

Everything you see is generated by code, frame by frame:

| Part | Where | What it does |
|---|---|---|
| Drawing | `js/draw.js` | Hand-drawn ink primitives: jittered strokes with a subtle 8 fps "line boil", flat fills, emotes |
| The little friend | `js/cube.js` | The mascot rig from the character sheet: squash & stretch, lean, arms, walking legs, 15 eye/mouth expressions |
| The human | `js/human.js` | Three simple rigs: seated back view, side view walking (IK legs/arms), front close-up |
| Staging | `js/world.js`, `js/room.js`, `js/props.js`, `js/render.js` | A real perspective camera over a world measured in centimetres; every prop is a hand-drawn billboard, so camera moves have true parallax and the 5 cm hero can walk through a giant desk |
| Light | `js/light.js` | A multiply "light map": lamp, moonlight, screen glow, hallway light, the orange glow of the little friend |
| Motion | `js/core.js`, `js/motion.js` | Keyframes, springs, landing squash, anticipation before hops, saccadic eye darts, waypoint choreography |
| The film | `js/acts/*.js`, `js/story.js`, `js/film.js` | Seven acts: world state as a pure function of time, a shot list with cameras, cuts, dissolves and fades |
| Player | `js/player.js`, `site_src/` | The web player |

`renderFrame(ctx, t)` is a pure function of time, which is what lets the same code drive the live web player and
the frame-exact MP4 render.

### Sound

- **Score** — `production/audio/score.py` composes an original score in code (a main theme, a sneaky pizzicato
  theme, a chase, a lullaby…), aligned to the story beats in `js/acts/times.js`, and renders it with FluidSynth +
  the FluidR3 GM soundfont.
- **Foley** — CC0 recordings from freesound.org and Kenney (see `CREDITS.md`), prepared by
  `production/audio/sfxlib.py` (clips included in `production/audio/clips/`).
- **Sync** — `production/tools/export_cues.mjs` runs the animation's world state at 120 Hz and exports every
  footstep, hop landing, key press, pen roll, switch, door and lid event. `production/audio/mix.py` places the
  sounds on those exact times, adds hand-placed sound design, ambience beds, the little friend's synthesized voice,
  reverb, and masters the soundtrack.

## Rebuild

Requirements: Node 18+, Playwright with Chromium, Python 3 with `numpy scipy soundfile mido fonttools`,
FluidSynth with `FluidR3_GM.sf2`, and an ffmpeg with libx264.

```sh
npm install                                             # esbuild (site bundle)
node production/tools/export_cues.mjs                   # story beats + animation events → production/build/cues.json
python3 production/audio/score.py                       # score → production/build/music.wav
python3 production/audio/mix.py                         # full mix → production/build/soundtrack.wav
node production/tools/build_site.mjs                    # site/ (bundled JS, subset fonts, encoded soundtrack)
node production/tools/render_video.cjs --bitrate 2750k  # frames → film/after-the-laptop-closes.mp4
```

For development, `node production/tools/serve.cjs 8080` serves the repo; `dev/frame.html` exposes
`renderAt(t)`, and `production/tools/snap.cjs` / `scan.cjs` render stills and contact sheets for review.
