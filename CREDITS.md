# Credits · 致谢

**关闭电脑之后 · After the Laptop Closes** — a short film drawn, animated, scored and mixed in code.

## Picture
- All drawing and animation: original, generated frame by frame by the code in `js/` (Canvas 2D).
- The little orange friend (小橙块) is fan art of the Claude Code mascot, drawn after the character sheet supplied for this project.

## Music
- Original score, composed in code (`production/audio/score.py`) and rendered with **FluidSynth** using the **FluidR3 GM** soundfont by Frank Wen (MIT licence).

## Fonts (SIL Open Font License 1.1)
- **Patrick Hand** — Patrick Wagesreiter (`fonts/OFL-PatrickHand.txt`)
- **ZCOOL KuaiLe** — ZCOOL (`fonts/OFL-ZCOOLKuaiLe.txt`)

## Sound effects
All recordings are **CC0 / public domain**. Trimmed, re-pitched, filtered and placed by `production/audio/mix.py`; the prepared clips ship in `production/audio/clips/`. The little friend's voice, its tiny footsteps, the fan whirr, the boot chime and the glow hum are synthesized (`production/audio/synth.py`).
